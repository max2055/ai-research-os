# Thesis

## Core judgment

待验证假设：在模型能力快速扩散时，repository context、evaluation、sandbox、
toolchain 和团队 workflow integration 可能比单一模型选择更持久。

## Reasoning chain

需要验证这些能力是否产生可衡量的成功率、切换成本和商业价值，而不是只增加产品
复杂度。

## Supporting evidence

尚无 reviewed Evidence。

## Contradicting evidence

尚无 reviewed Evidence。

## Alternative explanations

- 协议和基础设施可能快速标准化。
- 模型能力提升可能降低专有 context/evaluation 的价值。

## Key variables

- repository indexing quality、eval coverage、sandbox reliability、workflow switching。

## Falsification conditions

- 客户可以无成本在产品间迁移且结果无显著差异。
- 开放工具链完全替代专有集成。

## Investment implications

技术差异不能直接等同投资价值，需要结合采用、定价、成本和市场预期。

## Unknowns

- 差异化持续时间、企业付费意愿和维护成本。
