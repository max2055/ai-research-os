# Thesis

## Core judgment

待验证假设：软件开发入口可能从持续的人机 IDE 交互，部分迁移到可委派、异步执行和
回传结果的 Agent task layer。

## Reasoning chain

这是研究起点而非事实结论。需要分别验证任务范围、成功率、人工介入、团队采用和
长期留存。

## Supporting evidence

尚无 reviewed Evidence。

## Contradicting evidence

尚无 reviewed Evidence。

## Alternative explanations

- Agent 可能只是 IDE 内的增强功能，不形成独立任务入口。
- 高风险工程任务可能长期需要逐步人工控制。

## Key variables

- 异步任务占比、完成率、人工修正率、重复使用率。

## Falsification conditions

- 真实团队长期只用于低风险辅助任务。
- 异步任务没有稳定复用或生产部署。

## Investment implications

在采用、商业化和估值证据完成前，不形成证券选择结论。

## Unknowns

- 生产使用深度、团队留存、入口控制权和单位经济性。
