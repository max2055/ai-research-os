# Thesis

## Core judgment

待验证假设：Coding Agent 商业模式可能从固定 seat 扩展到 usage 或 task，但推理、
验证、sandbox 和支持成本可能限制可获得利润。

## Reasoning chain

必须分开观察标价、实际收入单位、用量、毛利率、失败重试和人工支持，不能由产品
定价页面直接推断商业质量。

## Supporting evidence

尚无 reviewed Evidence。

## Contradicting evidence

尚无 reviewed Evidence。

## Alternative explanations

- Seat bundle 可能继续是客户预算和厂商收入的主要单位。
- 模型成本下降可能快于 Agent 用量增长。

## Key variables

- seat/usage/task mix、推理成本、任务成功率、重试率、支持成本、净留存。

## Falsification conditions

- 主要收入长期保持 seat 且 Agent 不形成独立增量预算。
- usage/task 增长不能产生可持续毛利。

## Investment implications

在单位经济性、竞争和市场预期完成前，不形成证券选择结论。

## Unknowns

- 真实折扣、成本分摊、客户预算来源和收入替代。
