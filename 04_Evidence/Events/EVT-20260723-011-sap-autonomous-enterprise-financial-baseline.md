# Event

## Facts

SAP Q2 2026 披露 current cloud backlog 为 229 亿欧元，同比增长 27%；公司将战略表述为 Autonomous Enterprise，并列出若干 AI 和数据解决方案客户，但未独立披露 Agent 收入。

## Inferences

SAP 有稳定云业务和客户迁移基础，但现有公开数据不能区分 Agent 对增长的贡献。

## Research judgment

该事件主要建立经营基线，不能作为 Agent 商业成功证据。

## Alternative explanations

- Agent 价值可能通过云迁移和续费间接体现。
- AI 仍可能处于打包推广期。

## Unknowns

- Joule 活跃客户、任务量和收入。
- AI 与核心云增长的因果关系。
