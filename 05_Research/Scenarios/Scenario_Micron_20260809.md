# Scenario Worksheet — COM-micron

**As of**: 2026-08-09
**Question**: Micron 盈利与价格的三情景（E-021 3-company pilot）。

## Downside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: DRAM/HBM 高位盈利，ASP 波动区间 +40%/-40%
- 关键驱动 (3-5) / key drivers: 通用 DRAM 价格下行、供给转产、HBM 需求放缓
- 来源或明确 Judgment / source or judgment: EVT-20251003-001（ASP 波动）、EVT-20260601-044（份额）
- 传导机制 / transmission mechanism: 供给扩张 + HBM 转产通用 DRAM → 价格下行 → 毛利率压缩
- 经营结果 / operating result: FY2027 DRAM ASP 下行 >15%，收入下滑
- 财务结果 / financial result: 毛利率从高位回落至 30% 以下
- 估值含义 / valuation implication: 现价（$877）隐含的持续高盈利被修正
- 概率 / probability (若使用): 30%
- 催化剂 / catalysts: TrendForce 报告通用 DRAM 合约价转跌
- 证伪条件 / falsifiers: 通用 DRAM 价格连续两季上行
- 对冲因素 / countervailing factors: HBM 占比提升、AI 内存需求结构性

## Base scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: AI 内存需求强劲，HBM 占比上升
- 关键驱动 (3-5) / key drivers: AI 内存需求、HBM 挤占产能、DRAM 供需紧平衡
- 来源或明确 Judgment / source or judgment: EVT-20260625-001（HBM 需求）、EVT-20260728-036（SK hynix 创纪录）
- 传导机制 / transmission mechanism: AI 需求持续 + HBM 挤占 → 价格高位维持
- 经营结果 / operating result: DRAM ASP 持平或小幅波动，HBM 收入占比提升
- 财务结果 / financial result: 毛利率维持高位（40%+）
- 估值含义 / valuation implication: 估值与现价大致匹配
- 概率 / probability (若使用): 50%
- 催化剂 / catalysts: Micron 财报 HBM 出货与 ASP 数据
- 证伪条件 / falsifiers: ASP 下行 >10%
- 对冲因素 / countervailing factors: 周期属性始终存在

## Upside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: HBM 结构性短缺，AI 内存需求超预期
- 关键驱动 (3-5) / key drivers: HBM 供不应求、AI 训练/推理扩张、通用 DRAM 紧平衡
- 来源或明确 Judgment / source or judgment: EVT-20260625-001、EVT-20260728-036
- 传导机制 / transmission mechanism: HBM 短缺 → 定价权 → 盈利超预期
- 经营结果 / operating result: ASP 上行 >10%，HBM 收入占比大幅提升
- 财务结果 / financial result: 毛利率 >50%
- 估值含义 / valuation implication: 估值上修
- 概率 / probability (若使用): 20%
- 催化剂 / catalysts: HBM 合约价上调、AI 内存需求超预期
- 证伪条件 / falsifiers: ASP 上行 <10%
- 对冲因素 / countervailing factors: 供给扩张响应

## Two-variable sensitivity matrix

| 变量 1 \\ 变量 2 | AI 需求放缓 | AI 需求平稳 | AI 需求加速 |
|---|---|---|---|
| 供给扩张 | ASP -20% | ASP -5% | ASP +5% |
| 供给受限 | ASP -5% | ASP +10% | ASP +20% |

- 变量 1 (驱动): 供给扩张/转产
- 变量 2 (驱动): AI 内存需求
- 单元格含义 (结果变量): FY2027 DRAM ASP 变化

## Tail risk (可选)

- 内存超级周期见顶，价格断崖下行（历史 -40% 重演）。
- HBM 需求结构性证伪。

## Cross-scenario falsification

- 若通用 DRAM 合约价连续两季上行，Downside 证伪。
- 若 HBM 出货占比持续提升且价格高位，Upside 支撑。
