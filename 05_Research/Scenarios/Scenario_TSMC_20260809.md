# Scenario Worksheet — COM-tsmc

**As of**: 2026-08-09
**Question**: TSMC 先进节点增长与客户集中风险的三情景（E-021 3-company pilot）。

## Downside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: 先进节点占收入 63%，客户集中少数 AI 加速器厂商
- 关键驱动 (3-5) / key drivers: AI 客户资本开支放缓、客户自研/转单、地缘事件
- 来源或明确 Judgment / source or judgment: EVT-20260716-037（先进节点 63%）、EVT-20260302-047（竞争）
- 传导机制 / transmission mechanism: 客户集中需求放缓 + 自研分流 → 先进节点产能利用率下降 → 增速回落
- 经营结果 / operating result: 先进节点收入增速降至 <15%，产能利用率下探
- 财务结果 / financial result: 毛利率受压（先进节点占比下降 + 折旧增加）
- 估值含义 / valuation implication: 现价隐含的持续高增长被修正
- 概率 / probability (若使用): 25%
- 催化剂 / catalysts: 任一 AI 客户下季度资本开支指引下修或转单公告
- 证伪条件 / falsifiers: 先进节点收入占比与增速连续两季上升
- 对冲因素 / countervailing factors: 2nm/CoWoS 技术领先、NVIDIA 依赖

## Base scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: AI 加速器需求持续，先进节点紧俏
- 关键驱动 (3-5) / key drivers: AI 训练/推理需求、2nm 爬坡、CoWoS 供给
- 来源或明确 Judgment / source or judgment: EVT-20260416-033（2nm/CoWoS）、EVT-20260716-037
- 传导机制 / transmission mechanism: AI 需求持续 + 先进节点壁垒 → 增速维持、毛利率稳定
- 经营结果 / operating result: 先进节点收入增长 20-35%，占比维持 60%+
- 财务结果 / financial result: 毛利率 55-60% 维持
- 估值含义 / valuation implication: 估值与现价大致匹配
- 概率 / probability (若使用): 50%
- 催化剂 / catalysts: TSMC 季度财报先进节点占比与毛利率
- 证伪条件 / falsifiers: 先进节点收入增速 <20%
- 对冲因素 / countervailing factors: 客户集中度风险持续

## Upside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: AI 需求超预期，先进节点供不应求
- 关键驱动 (3-5) / key drivers: AI 推理需求爆发、2nm 客户扩增、NVIDIA Vera Rubin
- 来源或明确 Judgment / source or judgment: EVT-20260731-040（$100B 扩展）、EVT-20260302-048
- 传导机制 / transmission mechanism: 需求超预期 + 先进节点壁垒 → 定价权 → 增速与毛利率双升
- 经营结果 / operating result: 先进节点收入增长 >35%
- 财务结果 / financial result: 毛利率 >60%
- 估值含义 / valuation implication: 估值上修
- 概率 / probability (若使用): 25%
- 催化剂 / catalysts: 2nm 大客户签约、AI 需求超预期
- 证伪条件 / falsifiers: 先进节点收入增速 <35%
- 对冲因素 / countervailing factors: 客户集中度使波动放大

## Two-variable sensitivity matrix

| 变量 1 \\ 变量 2 | AI 需求放缓 | AI 需求平稳 | AI 需求加速 |
|---|---|---|---|
| 先进节点壁垒维持 | 增速 15% | 增速 25% | 增速 40% |
| 客户自研分流 | 增速 5% | 增速 15% | 增速 25% |

- 变量 1 (驱动): 先进节点壁垒/客户自研
- 变量 2 (驱动): AI 加速器需求
- 单元格含义 (结果变量): 先进节点收入增速

## Tail risk (可选)

- 地缘事件（台湾）中断先进节点供给 → 收入中断 + 估值折价。
- AI 泡沫破裂 → 先进节点需求塌方。

## Cross-scenario falsification

- 若先进节点收入占比连续两季下降且增速 <15%，Downside 概率上调。
- 若 2nm 客户扩增且增速 >35%，Upside 支撑。
