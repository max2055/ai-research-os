# Scenario Worksheet — COM-nvidia

**As of**: 2026-08-09
**Question**: NVIDIA 数据中心收入与定价权的三情景（E-021 3-company pilot）。

## Downside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: AI 资本开支前置高峰，HBM/先进封装供给紧张
- 关键驱动 (3-5) / key drivers: AI 资本开支放缓、HBM/先进封装成本上升、客户集中议价
- 来源或明确 Judgment / source or judgment: EVT-20260520-032（长交期+产能承诺）、EVT-20260225-035（ASP 下调）
- 传导机制 / transmission mechanism: 资本开支放缓 → 需求转弱 + 供给紧张缓解 → 定价权逆转 → 毛利率下行
- 经营结果 / operating result: 数据中心收入增速降至 <20%，交期正常化
- 财务结果 / financial result: 数据中心毛利率降至 70% 以下（当前 ~75%）
- 估值含义 / valuation implication: 现价隐含的持续高毛利被修正，估值下修
- 概率 / probability (若使用): 25%
- 催化剂 / catalysts: 任一超大规模厂商下季度资本开支指引下修
- 证伪条件 / falsifiers: 数据中心毛利率连续两季上升且 ASP 稳定
- 对冲因素 / countervailing factors: AWS/OpenAI $100B 多年承诺锁定部分需求

## Base scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: 需求旺盛，供给仍紧
- 关键驱动 (3-5) / key drivers: AI 训练/推理需求、供给爬坡、HBM 挤占
- 来源或明确 Judgment / source or judgment: EVT-20260520-038（$75.2B 季收入）、EVT-20260731-040
- 传导机制 / transmission mechanism: 需求持续 > 供给 → 交期维持、ASP 平稳、毛利率稳定
- 经营结果 / operating result: 数据中心收入增长 30-45% y/y
- 财务结果 / financial result: 毛利率 72-75% 维持
- 估值含义 / valuation implication: 估值与现价大致匹配
- 概率 / probability (若使用): 50%
- 催化剂 / catalysts: NVIDIA FY27 Q2 财报数据中心增速
- 证伪条件 / falsifiers: 收入增速 <30%
- 对冲因素 / countervailing factors: 供给扩产可能压缩交期溢价

## Upside scenario

- 时间线 / time horizon: Year
- 起点状态 / starting state: AI 需求超预期，供给瓶颈持续
- 关键驱动 (3-5) / key drivers: AI 推理需求爆发、Vera Rubin/HBM4 平台、供给约束
- 来源或明确 Judgment / source or judgment: EVT-20260731-040（$100B 扩展）、EVT-20260728-036
- 传导机制 / transmission mechanism: 推理需求爆发 + 供给瓶颈 → 卖方市场 → ASP 上行 + 毛利率升
- 经营结果 / operating result: 数据中心收入增长 >50% y/y
- 财务结果 / financial result: 毛利率 >75%
- 估值含义 / valuation implication: 估值上修
- 概率 / probability (若使用): 25%
- 催化剂 / catalysts: 推理需求超预期、HBM4 提前量产
- 证伪条件 / falsifiers: 收入增速 <50%
- 对冲因素 / countervailing factors: 客户自研芯片分流

## Two-variable sensitivity matrix

| 变量 1 \\ 变量 2 | 资本开支放缓 | 资本开支平稳 | 资本开支加速 |
|---|---|---|---|
| HBM 供给紧张 | 毛利率 68% | 毛利率 72% | 毛利率 75% |
| HBM 供给缓解 | 毛利率 70% | 毛利率 73% | 毛利率 74% |

- 变量 1 (驱动): HBM/先进封装供给
- 变量 2 (驱动): AI 资本开支
- 单元格含义 (结果变量): 数据中心毛利率

## Tail risk (可选)

- 地缘事件（台湾）中断先进封装供给 → 收入中断风险。
- AI 泡沫破裂 → 资本开支骤停 → 需求塌方。

## Cross-scenario falsification

- 若任一季数据中心毛利率 <70%，Downside 概率上调。
- 若交期显著缩短而收入仍高增，供给约束叙事证伪。
