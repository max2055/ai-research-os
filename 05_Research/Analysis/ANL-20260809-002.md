## Facts used

仅引用冻结输入 `EVT-20260601-044` 中的两条事实：

- **F1** — TrendForce 报告：2026 Q1 全球 DRAM 行业营收季增 81% 达 $97B；第一名 Samsung 营收 $37.32B、市占 38.5%，第二名 SK hynix 营收 $27.98B、市占 28.8%，第三名 Micron 营收 $21.75B、市占 22.4%。Samsung 的 ASP 增幅为三大原厂之首，且 server DRAM 营收占比最高，营收季增 93.4%。
- **F2** — TrendForce 报告：SK hynix 的 HBM 位元出货比重为三大原厂最高，然 2026 年 HBM 合约价下滑抑制其整体产品售价涨幅，Q1 营收季增 62.5%、市占 28.8%；Micron 营收季增 81.6%、市占 22.4% 持平前一季。

## Inferences

- **I1** — 行业营收季增 81% 至 $97B，且 Samsung ASP 大幅成长，推断 2026Q1 DRAM 处于需求拉动下的供给偏紧状态，制造环节（三大原厂）在总量层面握有定价权。
- **I2** — SK hynix HBM 位元出货比重最高，但 2026 HBM 合约价下滑抑制其营收增幅——推断 HBM 子环节出现"量升价跌"：出货规模领先未转化为价格保护，下游 HBM 采购方（AI 加速器/超大规模客户）在该子环节掌握较强议价权。
- **I3** — Samsung 同时拥有最高 ASP 增幅与最高 server DRAM 营收占比，推断利润池在同一制造环节内部从 HBM 差异化子段向高 ASP server DRAM 子段迁移。
- **I4** — 三家合计市占约 90%，推断 DRAM/HBM 制造环节为高度集中的寡头结构，资本开支壁垒构成该环节的稀缺资源（先进制程产能）控制力。
- **I5** — 三家营收全部环比高增（62.5%/81.6%/93.4%），推断本事件中的"受损"是相对议价权受损，而非绝对经营恶化。

## Judgments

- **J1** — 当前价值链中，DRAM/HBM 制造（晶圆厂+相关封装）环节同时控制稀缺资源（先进制程产能）与主要客户关系（Samsung 在 server DRAM 的客户关系最强），是价值链的中枢环节，且因 90% 集中度具有高进入壁垒。
- **J2** — 从本事件证据看，瓶颈并未移出制造环节，但在制造环节内部发生重心迁移：利润池自 HBM 差异化部分（合约价下行、量增不保价）向高 ASP server DRAM 部分（Samsung 主导）移动。
- **J3** — SK hynix 是本事件中最符合"增长但无法保留利润"特征的环节参与者：HBM 位元份额最高（增长），但 2026 合约价下滑使其无法将量优势转化为同等的营收/ASP 增幅。
- **J4** — 证据强度：营收与市占为第三方估计（B 级来源），利润池判断由营收/ASP 代理推断，而非公司披露的毛利率数据，故 J2、J3 属于中等置信度的推断，非直接事实。
- **J5** — 本事件未提供设备/材料/封测/渠道等上下游环节的数据，故价值链结论限于制造环节及其内部子段层面。

- **A2** — 2026 HBM 合约价下滑可能是一次性合约重谈（年度/半年度合约调整）的时点效应，而非趋势性定价权流失。
- **A3** — TrendForce 数据为调研估计，估值口径（营收 vs 位元出货）与实际份额可能存在偏差，三家相对地位可能部分失真。
- **A4** — DRAM 与 HBM 是不同细分市场，三家在不同细分竞争力不同；本事件将两者混在同一行业营收池中处理，可能掩盖细分层面不同的竞争逻辑。

## Mechanism

**传导路径**：

- 路径一（总量涨价路径）：AI 资本开支拉动的需求 → server DRAM 供给偏紧 → ASP 上行 → 制造环节整体获利；在该路径中，Samsung 因 server 占比最高而弹性最大。
- 路径二（HBM 价格下压路径）：HBM 供应放量（SK hynix 位元出货比重最高 = 供给能力领先）→ 2026 合约价下滑 → 供应商 ASP 受限 → HBM 子段利润池向采购方（下游 AI 芯片/云厂客户）转移。
- 两条路径共同作用的结果是：行业 $97B 的总量利润池上升，但 HBM 比重高者（SK hynix）在池内分配中相对吃亏，server DRAM 比重高者（Samsung）相对获益。

**时间滞后**：

- 合约价格滞后：HBM 合约价（2026 年下滑）大概率于 2025 年谈判锁定；SK hynix 当前营收承压反映的是过去谈判期的议价结果——议价权变化对营收的传导滞后约 1-2 个季度（季度/年度合约为主要周期）。
- 产能投资滞后：当前产能供给反映 2023-2024 年的资本开支决策，即供给对需求变化的滞后为 2-3 年；这意味着当前 ASP 上行与 HBM 价跌均含有 2 年前产能决策的影响，非纯需求面冲击。
- 客户关系迁移滞后：客户对三星的 server 采购倾斜反映数个季度的产品导入周期，客户关系变动传导至市占约需 2-4 个季度。
- 方向判断：短期（季度）内 Samsung 受益延续性取决于 Q2/Q3 的 server DRAM 供需；中期（年度）若 HBM 合约价在 2026 下半年重谈后回升，SK hynix 的相对受损可能暂时扭转；长期（多年）则需观察 HBM4 迭代中哪家能将技术份额转化为价格溢价。
