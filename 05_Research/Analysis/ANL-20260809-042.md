## Alternative explanations

- **早期采纳阶段**：Agent 可能仅服务于少数早期客户（如列表中提到的 AI 客户），尚未形成规模化收入，故被并入整体业绩。
- **战略叙事优先**：公司用 “Autonomous Enterprise” 作为资本市场叙事工具，而实际收入贡献滞后于叙事，这是科技企业常见策略。

## Downside scenario

- **驱动变量**：Agent 收入贡献极小（不足云收入的 1%），且无独立披露；云积压订单增速从 27% 下滑至 15% 以下。
- **概率**：25%（研究判断）。
- **结果**：市场无法验证 Agent 价值，估值溢价消除；企业客户对 AI 功能转向观望，导致续费率承压。SAP 可能继续使用 “AI 客户数量” 等软指标来支撑叙事。
- **时间线**：未来 **2 quarters** 内数据若未改善，该情景概率会上升；**1 year** 内若 Agent 仍无独立指标，将确认为下行。
- **反面因素**：云积压订单现有 27% 增速为下行情景提供了缓冲垫，客户迁移惯性可能推迟衰退。

## Base scenario

- **驱动变量**：Agent 收入隐含于云积压中，但无法分开核算；云积压增速维持在 20%-25%，AI 功能作为增值服务推动续费。
- **概率**：55%（研究判断）。
- **结果**：SAP 保持稳健增长，Agent 逐渐渗透到现有客户群，但市场对 Agent 的独立价值保持中性预期。公司继续以 “Autonomous Enterprise” 为战略叙事，但财务上不拆分。
- **时间线**：持续至 **1 year**，并可能延续到 **multi-year**。该情景下，公司每季度公布云积压绝对值和增速，但缺乏细节。
- **反面因素**：竞争对手（如大型云厂商）可能推出更激进的 AI 定价，迫使 SAP 在价格或投入上做出让步。

## Upside scenario

- **驱动变量**：SAP 在后续季度（2026Q3 或 2027 年）首次独立披露 Agent 相关收入（或 ARR），且数值超出市场推测（如贡献云增长量的 30% 以上）；Joule 生产任务量环比增长超过 100%。
- **概率**：20%（研究判断）。
- **结果**：市场重新评估 SAP 作为 “Agent 商业平台” 的定位，云积压订单增速加速至 35% 以上，公司获得额外增长引擎，并可能引导行业对 AI 软件收入进行重新标价。
- **时间线**：催化剂可能在 **1-2 quarters** 内出现（若披露调整），但验证需要 **multi-year** 观察持续性。
- **反面因素**：即便披露，也可能发现 Agent 收入来自内部迁移带来的收入重分类，而非新业务增量；或单价远预期。

## Sensitivity and catalysts

- **敏感性**：
  - 云积压订单增速每变动 1 个百分点，对三个情景概率的权重影响约为 5%——增速高于 27% 强化 Upside，低于 20% 强化 Downside。
  - Agent 披露的颗粒度（收入 vs 客户数 vs 任务量）对情景判断影响最大：若披露收入，则全面转向定量验证。
- **催化剂**（按时间顺序）：
  - 短期（下一个季度财报）：是否提及 AI/Agent 收入拆分或 Joule 的付费客户数。
  - 中期（半年内）：是否有大型客户案例将 Agent 与明确业务成果（如成本降低、收入提升）关联。
  - 长期（一年后）：SAP 是否能保持云积压增速 20% 以上，同时公布 AI 相关毛利率。
- **反催化剂**：公司明确表示 “不单独披露 Agent 收入” 或 “Agent 仍处于预发布阶段”，将立即提升 Downside 概率。

## Falsification conditions

以下条件若出现，将直接否定或重构上述情景：

- **证伪 Downside**：若 SAP 在一个季度内披露 Agent 收入（哪怕绝对值较小），且云积压增速不下降，则 Downside 情景失去基础。
- **证伪 Base**：若云积压增速连续两个季度低于 10%，且 Agent 披露仍为零，则 Base 情景被打破，必须转向更悲观假设。
- **证伪 Upside**：若 SAP 披露 Agent 收入，但发现其占云收入比例低于 5%，或客户名单中均为非付费试点，则 Upside 情景证伪，且需调低对整个 AI 叙事的信任。
- **跨情景证伪**：若 SAP 明确宣布将 Agent 收入永久并入云收入且不提供拆分，则所有依赖独立披露的验证手段失效；此时必须将情景依据改为云积压增速本身作为唯一可观察变量。
