## Facts established

- **队列只读、proposal-only**：`candidates list/show` 不改任何权威事实；
  enqueue 无旁路（B-018 约束"无权威写入旁路"）。操作库可重建、非权威。
- **enrich 回填**：`candidates enrich [--apply]` 对 `status='new'` 且
  `priority_score IS NULL` 的候选计算 B-015 entity / B-016 sector / B-017
  score 并写回（entity_proposals_json / sector_proposals_json /
  reason_codes_json / priority_score / model_version）。幂等：已打分候选跳过。
- **representative 判定**：cluster 内最早 created（tie 按 candidate_id）为
  representative；变体获 dup_pen 0.5。cluster_size 计入 novelty 维度。
- **list 排序与过滤**：按 priority 降序（NULL 排最后）；`--status /
  --channel / --entity / --tier / --min-priority / --limit`。tier 经 entity
  proposal → Universe coverage_tier 解析。
- **enrich 接入 discover 写路径**：`discover run --apply` 现在直接产出
  带评分的候选，队列立即可审。
