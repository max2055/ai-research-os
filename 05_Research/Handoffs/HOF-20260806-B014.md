## Facts established

- **exact dedup**：canonical_url 或 content_fingerprint 相同 → 同 cluster。
- **near dedup**：normalize_title（小写/去标点/去 `-NN` 变体后缀）相同 → 同 cluster。
- **cluster 不丢记录**：所有候选保留，`duplicate_cluster_id` 标记归属
  （Phase 2 §5.2："近似重复只形成 cluster，不自动删除候选"）。
- **跨 run 扩展**：新 run 加载已有 cluster 索引（normalized title → cluster），
  重复标题并入旧 cluster 而非开新。
