## Facts established

- **schedule parser**：`interval_from_schedule`（daily / daily Nx / every N
  hours\|minutes\|days\|weeks / hourly / weekly）；不可解析 → None → 视为
  不到期（不自动跑无法排期的 channel，用 `channels check` 人工发现）。
- **`discover due` schedule-aware**：reviewed+enabled+非 restricted，按
  channel schedule + discovery_runs 上次 run 算到期；从未 run → 到期。
- **无重叠 lock**：`discover run --apply` 开始写 `running` 行；同 channel
  已有 running 行则拒绝；>30min（`LOCK_STALE`）的 stale running 回收为
  failed → 重启后可恢复、不会永久锁死。
- **retention sweep 落地**：schema **v2** 去掉 candidate_actions FK（审计行
  独立于候选保留，ADR §3"保留 action 审计行"）+ `candidates purge [--apply]`
  物理删除 dismissed/expired 候选行；`jobs run expire` = expire + purge。
- **JobSchema 变更**：job_name literal 扩到 discover/expire（实现已批准 §7/
  §10 的 `jobs run discover / daily-brief` CLI 面，非新治理决策）。
- **launchd runbook**：`StartInterval=21600`（6h，对齐最高频 schedule）+
  `RunAtLoad`（重启补跑）+ wrapper 逐 channel（单 channel 失败不中止）。
