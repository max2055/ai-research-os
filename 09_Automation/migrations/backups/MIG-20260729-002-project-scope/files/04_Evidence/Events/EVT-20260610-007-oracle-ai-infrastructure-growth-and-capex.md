# Event

## Facts

Oracle FY2026 披露 Cloud Infrastructure 高增长，Cloud Applications Q4 同比增长 10%；FY2026 自由现金流为负 237 亿美元。公司将大量 RPO 增量归因于大型 AI 基础设施合同。

## Inferences

Oracle 的 AI 经营增长当前可能主要由基础设施驱动，不能把 AI 总体增长直接归因于 Fusion Agent。

## Research judgment

该事件是研究隔离规则的实例：基础设施受益不等于企业 Agent 应用商业化已验证。

## Alternative explanations

- 基础设施客户未来可能带动数据库和应用交叉销售。
- Agent Studio 免费嵌入可能通过提高 Fusion 增长体现。

## Unknowns

- Fusion Agent 客户数、使用量和收入贡献。
- AI 基础设施投资回报周期。

## Follow-up indicators

- Fusion Cloud ERP 增长。
- Agent Studio 采用与使用指标。
- 自由现金流改善。
