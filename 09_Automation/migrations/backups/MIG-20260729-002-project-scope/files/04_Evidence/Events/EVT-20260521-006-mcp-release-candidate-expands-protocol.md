# Event

## Facts

MCP 项目维护者发布 2026-07-28 候选规范，提出无状态核心、Extensions、Tasks、MCP Apps、授权强化和正式弃用政策。

## Inferences

MCP 的设计范围正从简单工具连接扩展到长任务、用户界面、授权和协议治理，可能降低跨平台 Agent 集成成本。

## Research judgment

开放协议一方面支持跨系统控制层，另一方面可能削弱单一厂商对连接器和上下文接口的锁定。
