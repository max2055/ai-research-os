# Source

## Source summary

Anthropic 官方宣布将 MCP 捐赠给 Linux Foundation 旗下 Agentic AI Foundation。

## Why it matters

说明工具协议正在从单一厂商能力转为开放生态标准，可能同时扩大 Agent 生态并降低部分平台锁定。

## Relevant sections

- Anthropic 披露 MCP 已被多个主要 AI 和开发平台采用。
- 基础设施提供商支持企业级 MCP 部署。
- MCP 进入由多家公司支持的基金会治理结构。
