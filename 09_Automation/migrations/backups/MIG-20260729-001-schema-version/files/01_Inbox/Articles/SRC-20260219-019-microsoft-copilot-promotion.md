# Source

## Source summary

Microsoft 官方 AI Business Solutions 材料，包含特定时期和条件下的 Microsoft 365 Copilot 推广价格与席位要求。

## Why it matters

为 Microsoft Copilot 仍以企业席位和组织覆盖率为重要购买单位提供定价线索，可作为 THS-003 的反面或情境证据。

## Relevant sections

- 促销要求至少购买 300 个许可证。
- 促销与组织信息工作者席位覆盖率相关。
- Copilot Chat 对符合条件的 Microsoft Entra ID 用户可不额外收费。

## Reliability notes

A 级官方材料，但属于限时促销而非完整长期价目表，不能代表所有地区、客户或 Agent 产品定价。
