# Source

## Source summary

Oracle 官方 Q4 和 FY2026 财务结果，报告期截至 2026-05-31。

## Why it matters

建立 Oracle 云基础设施、云应用、Fusion 与资本开支的经营基线。

## Relevant sections

- 公司披露 FY2026 总收入 674 亿美元。
- Q4 Cloud Applications 收入 41 亿美元，同比增长 10%。
- FY2026 自由现金流为负 237 亿美元，主要受云基础设施投资影响。
- 公司将大量 RPO 增量归因于大型 AI 基础设施合同。

## Reliability notes

A 级正式财务披露。AI 基础设施增长不能直接证明 Fusion Agent 商业化；两类业务必须分开分析。
