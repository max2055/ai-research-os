# Event

## Facts

Microsoft 官方促销材料要求至少购买 300 个许可证，并将优惠与组织信息工作者席位覆盖率关联。材料同时说明符合条件的 Entra ID 用户可获得不额外收费的 Copilot Chat。

## Inferences

Microsoft 在该促销中仍使用席位和组织覆盖率作为重要商业单位，说明 Agent/Copilot 商业化并未简单脱离席位模式。

## Research judgment

这是 THS-003 的情境或弱反面证据：定价迁移可能表现为席位与用量并存，而不是席位被快速替代。

## Thesis impact

| Thesis ID | Relationship | Explanation | Proposed confidence change |
|---|---|---|---|
| THS-003 | contradicting | 限时方案仍强化席位覆盖，但不能代表长期完整定价 | 不调整，待正式价目表 |

## Alternative explanations

- 促销只是获客工具，长期 Agent 定价可能不同。
- Copilot 与自主 Agent 可能使用不同商业模式。

## Unknowns

- 标准非促销价格与 Agent 用量成本。
- 客户实际采购组合。

## Follow-up indicators

- Microsoft 官方完整价目表。
- Copilot Studio 和 Agent 运行的用量计价。
