# Event

## Facts

Microsoft 在 FY26 Q3 结果中披露 AI 业务年度收入运行率超过 370 亿美元，同比增长 123%。同期 Microsoft 365 Commercial cloud 收入增长 19%，Dynamics 365 收入增长 22%。

## Inferences

Microsoft 已通过云和软件分发形成大规模 AI 收入，但公开指标未拆分基础设施、模型服务、Copilot 和 Agent。

## Research judgment

事件为 Microsoft 的分发和商业化能力提供背景支持，但对企业软件 Agent Thesis 的区分度有限。

## Alternative explanations

- 收入可能主要来自 AI 基础设施而非企业 Agent。
- 传统云增长可能与 Agent 无直接关系。

## Unknowns

- AI 收入构成。
- Copilot/Agent 收入、使用率和利润率。

## Follow-up indicators

- Copilot 和 Agent 单独披露。
- 企业生产采用和用量指标。
