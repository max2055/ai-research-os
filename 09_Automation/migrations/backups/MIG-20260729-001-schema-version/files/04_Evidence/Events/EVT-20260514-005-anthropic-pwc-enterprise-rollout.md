# Event

## Facts

Anthropic 与 PwC 宣布扩大合作，包括员工部署、联合中心和培训计划。Anthropic 文章描述若干生产项目及交付时间改善，其中包括保险承保流程案例。

## Inferences

模型厂商可能通过咨询和系统集成伙伴进入核心企业流程，而不必直接拥有所有客户实施能力。

## Research judgment

该事件对 AI Native 厂商进入大型企业提供初步支持，但证据由供应商发布、缺少独立方法，区分度有限。
