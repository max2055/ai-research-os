# Company Profile

## Company role in the value chain

Oracle 覆盖数据库、云基础设施和 Fusion 企业应用，并把 Agent 构建、执行和治理放入 Fusion 运行时。

## Products

Fusion Applications、Oracle AI Agent Studio、OCI 及相关数据库产品。

## Customers and distribution

Fusion 和数据库客户构成企业数据与流程分发基础。首轮尚缺最新财报来源和 Agent 采用数据。

## Business model

Oracle 表示 AI Agent Studio 对 Fusion 客户不额外收费；需判断 Agent 是促进云迁移、提高续费还是形成独立收入。

## Revenue and profitability

待注册最新财务结果。

## Technology strategy

Agent 原生访问 Fusion 业务对象、API、知识库、权限、审批和审计，并支持第三方 Agent。

## Competitive advantages

候选优势是数据库、业务对象、ERP 工作流和运行时治理。尚未验证客户采用与跨非 Oracle 系统能力。

## Risks

- 免费嵌入难以形成可分拆收入。
- 产品数量不等于生产使用。
- 闭环生态可能限制第三方采用。
- 云和应用产品复杂度。
