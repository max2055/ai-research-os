# 阶段 0：首个研究项目章程

## 1. 研究主题

**AI Agent 时代，企业软件价值链是否正在重构？**

版本：v0.1  
状态：Active  
建立日期：2026-07-29  
首次阶段性复盘：完成第一篇研究备忘录后  
长期验证窗口：未来 3～5 年

## 2. 研究目的

本项目用于验证 AI Research OS 的最小研究闭环，而不是一次性回答整个 AI 行业的投资问题。

本轮研究需要回答：

1. AI Agent 是否正在改变企业软件的产品形态和用户交互入口？
2. 企业软件价值将向哪些环节迁移？
3. 现有软件厂商与 AI Native 厂商分别拥有什么优势和约束？
4. 传统席位制商业模式是否会被使用量、任务量或结果定价削弱？
5. 哪些变化已经得到商业数据验证，哪些仍是技术叙事？
6. 上述变化可能给哪些上市公司带来机会或风险？

## 3. 研究边界

### 纳入范围

- 面向企业客户的软件和 Agent 平台。
- Agent 对界面、工作流、数据、权限、分发和定价的影响。
- Microsoft、Salesforce、ServiceNow、Oracle、SAP、Palantir。
- OpenAI、Anthropic 等模型和 Agent 平台对企业软件生态的影响。
- 产品发布、客户采用、商业化、管理层表述和可验证经营指标。

### 暂不纳入

- 消费级 AI 应用。
- AI 芯片和数据中心的完整投资研究。
- 所有垂直行业应用的全面覆盖。
- 量化交易、自动选股和自动买卖建议。
- 完整 DCF 或复杂估值模型。
- 对全部企业软件公司的穷举研究。

如某项外部因素会直接改变本研究的核心判断，可以将其作为关联证据记录，但不扩展为独立研究项目。

## 4. 初始价值链模型

```text
算力与云
→ 基础模型
→ Agent 平台与开发工具
→ 企业数据、权限与工作流
→ 企业软件与系统入口
→ 业务任务执行
→ 企业客户与最终用户
```

重点观察价值和控制权是否发生以下迁移：

- 从图形界面转向自然语言和 Agent 入口。
- 从功能模块转向任务执行和结果交付。
- 从软件席位转向使用量、任务量或结果定价。
- 从通用模型能力转向企业数据、权限、流程和分发。
- 从单一应用转向跨应用的 Agent 控制层。

## 5. 初始研究假设

### T01：界面价值下降

Agent 将逐步成为企业软件的新入口，传统图形界面的部分价值会下降。

可证伪条件：

- Agent 长期只能作为辅助功能，无法承担高频核心工作流。
- 企业用户继续主要通过原有应用界面完成任务。
- Agent 使用率和留存率在试点后显著下降。

### T02：数据、权限和工作流成为主要护城河

模型能力趋于普及时，企业数据访问、权限治理、业务流程嵌入和系统集成将比单纯模型能力更重要。

可证伪条件：

- 通用模型厂商可以绕过现有软件厂商直接获得企业数据和流程控制权。
- 企业客户不愿为数据治理、权限或工作流集成支付溢价。

### T03：传统定价模式受到冲击

随着 Agent 替代部分人工操作，传统按用户席位收费将逐步受到使用量、任务量或结果定价的挑战。

可证伪条件：

- 主要厂商能够长期保持席位制且不影响增长和客户留存。
- Agent 产品仍主要作为席位附加功能销售。

### T04：现有企业软件厂商具有分发优势和创新者困境

现有厂商拥有客户、数据、权限和分发优势，但其既有产品架构与收入模式可能限制自我重构。

可证伪条件：

- 现有厂商顺利完成 Agent 化转型，且未出现收入模式冲突。
- AI Native 厂商无法突破企业采购、安全与集成壁垒。

### T05：Agent 平台可能形成新的控制层

能够跨系统规划、调用工具和执行任务的 Agent 平台可能成为企业软件之上的新控制层。

可证伪条件：

- 企业拒绝跨系统 Agent，Agent 长期被限制在单一应用内。
- 安全、准确性、权限和责任问题使跨系统执行无法规模化。
- 企业软件厂商通过封闭生态阻止独立 Agent 平台获得控制权。

## 6. 首批研究对象

| 类型 | 对象 | 主要观察点 |

| 综合平台 | Microsoft | Copilot 商业化、企业分发、数据与权限体系 |

## 7. 关键观察指标

### 产品与采用

- Agent 产品的付费客户数、活跃用户数与使用频次。
- 从试点进入生产环境的比例。
- 客户是否将 Agent 用于核心工作流。
- 单个 Agent 可执行的任务范围和跨系统能力。
- 客户案例是否包含可验证的效率或收入改善。

### 商业化

- Agent 相关收入、ARR、订单或剩余履约义务。
- 定价单位：席位、调用、任务、算力消耗或结果。
- Agent 收入是新增预算还是替代原有软件预算。
- 毛利率、推理成本和服务实施成本。
- 是否出现席位减少但使用量增长的现象。

### 竞争与护城河

- 企业数据和权限由谁控制。
- Agent 入口由模型厂商还是应用厂商控制。
- 跨应用协议、工具调用和生态兼容性。
- 客户迁移成本与供应商锁定程度。
- AI Native 厂商进入大型企业的速度。

### 风险与约束

- 准确性、可解释性和责任归属。
- 数据安全、权限治理和监管。
- 推理成本和延迟。
- 企业流程改造和员工采用阻力。
- 模型能力商品化对各层价值的影响。
