## Scope and authority

This package closes Candidate dismiss/restore/promote Web parity and the product
capability registry. It does not close research-object approval/editing, operations,
backup/recovery, release parity, CLI retirement, or any F-023 human/time-dependent Gate.
Promotion creates a `review_status: pending` Source; automation still cannot approve a
research object or change a Thesis conclusion/confidence.

## Delivered contract

- 96/96 current argparse leaf commands have one typed product disposition and authority.
- Exact non-GET allowlist: three `/llm/*` routes plus dismiss/restore/promote preview and
  commit routes, nine total.
- Commit forms accept only session-bound CSRF and a 10-minute signed one-use preview token.
- Restore commits Candidate/action/audit in one SQLite transaction.
- Promote captures once, signs bounded metadata and hashes, then commits that frozen plan.
  It conditionally links the Candidate, records action/audit, and compensates published
  files with a redacted recovery manifest on post-publish failure.
- License restrictions, canonical duplicate checks, repository validation, Source enums,
  Project existence, and SEC contact User-Agent remain owned by domain services.
