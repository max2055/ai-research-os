# Source

## Source summary

Oracle 官方发布 Fusion Agentic Applications 和 AI Agent Studio 新构建体验。

## Why it matters

明确展示现有 ERP 厂商如何把 Agent 嵌入业务对象、工作流、安全、审批和审计之中。

## Relevant sections

- Agentic Applications 在 Fusion 运行时内执行。
- Agent 继承 Fusion 安全、治理、审批和审计控制。
- 产品支持 Oracle、合作伙伴和第三方 Agent。
- Oracle 表示 AI Agent Studio 对 Fusion Applications 客户不额外收费。

## Reliability notes

A 级公司正式产品公告。产品数量、专家数量和可用性由公司披露；“不额外收费”不代表整体使用成本为零。
