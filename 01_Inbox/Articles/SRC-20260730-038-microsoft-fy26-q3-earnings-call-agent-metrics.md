## Source summary

Microsoft FY26 Q3 正式电话会分别披露公司整体 AI ARR、Microsoft 365 Copilot
付费席位、第一方 Agent 活跃使用、Copilot Credit 消耗型购买、Agent 365 管理对象数量，
以及 LinkedIn Talent Solutions Agent 产品的年化收入。

## Why it matters

该材料能把席位、使用强度、消费型 credits、受管理 Agent 数量和部分产品收入拆开，
避免把“Agent 数量”或公司整体 AI ARR 误当成 Agent 运行量或独立财务贡献。
