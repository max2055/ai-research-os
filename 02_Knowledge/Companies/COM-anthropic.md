# Company Profile

## Company role in the value chain

Anthropic 提供 Claude 模型、Agent 开发能力、企业产品与 MCP 开放协议，并通过云和咨询伙伴进入企业。

## Products

Claude Enterprise、Claude Code、Claude Cowork、Claude Agent SDK、MCP。

## Customers and distribution

主要通过直接企业产品、三大云平台和咨询/系统集成伙伴分发。伙伴案例需要与实际客户独立核验。

## Business model

模型 API 用量、企业席位和合作伙伴渠道。Agent 产品对收入结构的贡献尚不透明。

## Revenue and profitability

非上市公司，需寻找可靠经营指标和企业采用数据。

## Technology strategy

强调 Tool Use、Agent SDK、MCP 连接器和长任务 Agent，并把 MCP 转入开放基金会治理。

## Competitive advantages

候选优势是模型能力、开发工具、开放协议影响力和企业伙伴网络。开放协议也可能降低自身锁定。

## Risks

- 模型竞争和推理成本。
- 依赖云与实施伙伴控制客户关系。
- 开放 MCP 生态价值可能由其他平台获取。
- 客户案例由供应商发布，证据独立性有限。

## Valuation context

非公开市场研究，暂不进行公开股票估值。

## Catalysts

- 企业产品定价和采用。
- 可独立核验的生产案例。
- MCP 生态治理和企业标准化进展。
