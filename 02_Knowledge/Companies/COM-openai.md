# Company Profile

## Company role in the value chain

OpenAI 同时提供模型、API、Agent SDK、工作空间和企业 Agent，可能从模型供应商向用户入口与工作流平台扩展。

## Products

ChatGPT Enterprise/Business、Workspace Agents、Responses API、Agents SDK、Codex。

## Customers and distribution

拥有消费者、开发者和企业入口。Workspace Agents 仍处 research preview，缺少生产采用数据。

## Business model

同时存在用户席位、API 用量和 Agent 运行消耗。需要研究模型收入与 Agent 平台收入的边界。

## Revenue and profitability

非上市公司，首轮使用产品与合作伙伴披露；需寻找可靠经营与企业采用资料。

## Technology strategy

把模型、工具、执行环境、SDK、企业连接器、权限和 Workspace 组合为 Agent 平台。

## Competitive advantages

候选优势是模型、开发者生态、ChatGPT 分发和 Agent 运行基础设施。需验证企业上下文与治理能力。

## Risks

- 与 Microsoft 及企业软件合作伙伴的竞合。
- 企业数据、权限和工作流掌握不足。
- 模型竞争与推理成本。
- 预览产品和产品路线变化。

## Valuation context

非公开市场研究，暂不进行公开股票估值。

## Catalysts

- Workspace Agents 正式可用及定价。
- 企业采用和任务完成数据。
- Agent SDK 与企业连接器生态扩展。
